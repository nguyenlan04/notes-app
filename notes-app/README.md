Notes App (Offline + Markdown)

1.Ứng dụng ghi chú chạy offline, lưu dữ liệu bằng localStorage, hỗ trợ Markdown cơ bản 
2.Tính năng
- Tạo / sửa / xóa ghi chú
- Tìm kiếm theo tiêu đề/nội dung
- Xem trước Markdown (toggle 👁)
- Tự động lưu sau khi gõ
- Lưu cục bộ (offline) bằng localStorage
- UI gọn, responsive

3.Công nghệ
- HTML + CSS + JavaScript thuần
- Không phụ thuộc CDN (chạy offline)

4.Cách chạy
1. Tải về hoặc clone repo
2. Mở `index.html` bằng trình duyệt (double-click là chạy)
